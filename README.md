## 📖 The Story Behind The Invitation

When **Ahmed** and **Basmala** set their date for **October 30, 2026**, they envisioned an invitation that transcended traditional paper cards and fleeting chat messages. They wanted a living digital experience: one that reflects the elegance of royal red velvet roses, honors sacred traditions, and offers guests an effortless, joyful way to celebrate and RSVP from anywhere in the world.

From the first delicate touch of the **"Open Invitation"** envelope to the gentle melodies of *El-Leil We Samah*, every transition and font choice was crafted to deliver an unforgettable emotional keepsake.

---

## ✨ Features & Architecture Highlights

### 🎬 1. Cinematic Interactive Cover
- **Velvet Rose Frame**: Immersive full-bleed backdrop featuring rich velvet roses, gold tassels, and relief damask.
- **Dynamic Sparkle Engine**: Custom multi-layered animated SVG sparkles with random staggered trajectory algorithms.
- **Frosted Glassmorphism**: High-contrast, blur-filtered card container engineered for pristine readability across all display types.

### ⏳ 2. Live Synchronized Flip Countdown
- Precision down-to-the-second countdown targeting **Friday, October 30, 2026, 7:00 PM**.
- Animated 3D flip digits with depth perspective, realistic split lines, and pulse separators.
- Dual Arabic and English time unit labels (*Days / يوم*, *Hours / ساعة*, *Minutes / دقيقة*, *Seconds / ثانية*).

### 📅 3. Interactive Calendar & 1-Click `.ics` Export
- Full monthly calendar component displaying the wedding month (October 2026).
- Heart-pulsing indicator highlighting the 30th of October with day status badges.
- Native `.ics` (iCalendar) generation: guests can add the wedding directly to **Apple Calendar**, **Google Calendar**, and **Outlook** with 1 click.

### 📸 4. Archival Art Photo Gallery
- Dual heirloom layout honoring both childhood memories (*Then • طفولتنا*) and the wedding day (*Now • عقد القران*).
- Double gold-filigree bordered frames with inner corner ornaments.
- Interactive live heart-reaction counters.
- Fullscreen high-resolution lightbox modal with smooth spring animations.

### 📍 5. Smart Venue & GPS Navigation
- Exact family residence location: **31 Ibrahim El-Desouky St., Ezbet El-Ahaly, El Qanater El Khayreya**.
- Live Google Maps satellite/street embed centered on GPS coordinates `30°12'00.1"N 31°06'24.6"E`.
- Instant GPS navigation button that opens **Google Maps App** directly on guests' mobile phones.

### 💌 6. Real-Time RSVP System & CSV Export
- Interactive modal form allowing guests to submit their name, number of attendees, and a personal prayer.
- Localized persistence with cross-tab instant synchronization.
- **CSV Data Export**: Automatically formats attendee lists with Arabic UTF-8 BOM encoding for seamless Excel viewing.

### 📖 7. Confidential 3D Guestbook (`#/guestbook-private`)
- A hidden virtual 3D guestbook for the bride and groom.
- Realistic 3D book physics with page-turning animations, aged paper shaders, book spine shadows, and keyboard arrow controls.
- Quick-copy attendance summary for family planning.

### 🎵 8. Ambient Soundtrack & Audio Controller
- Features the classic love anthem *الليل وسماه*.
- Discreet floating player with rotating disc animation, play/pause controls, and volume state handling.

## 🚀 Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0 or higher recommended)
- `npm` or `pnpm` / `yarn`

### 1. Clone the repository
```bash
git clone https://github.com/Bavly-Hamdy/Engagment-V2.git
cd Engagment-V2
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be generated inside the `dist/` directory.

## 🌐 Deployment

### GitHub Pages
This project is pre-configured with a relative base path for GitHub Pages. You can deploy it using GitHub Actions or:
```bash
npm run build
# Deploy dist directory to gh-pages branch
```

### Vercel / Netlify
Connect your repository to Vercel or Netlify. Set the build command to `npm run build` and the output directory to `dist`.
